# 일본어 단어 시험

일본어 시험범위 단어를 반복해서 외우고 직접 시험 보는 프로그램.

**현재 상태: 설계 단계.** 학습지·교재를 아직 받지 못해 단어 데이터가 비어 있습니다.

- 요구사항 정의서: [`docs/PRD.md`](docs/PRD.md)

## 문제 유형

| 유형 | 형태 | 예 |
|---|---|---|
| 일본어 → 뜻 | 뜻 5지선다 | `食べ物` → "음식" |
| 뜻 → 일본어 | 직접 쓰기 | "음식" → `たべもの` |
| 예문 빈칸 | 문장 속 빈칸 채우기 | `好きな____は何ですか。` |

가운데가 핵심 유형입니다.

## 두 가지 전제

**답은 가나로 씁니다.** 시험범위가 히라가나·가타카나 표기만 요구하므로,
한자를 쓸 수 있는지는 채점하지 않습니다. 한자는 읽으라고 보여 주기만 합니다.

**히라가나와 가타카나는 엄격히 구분합니다.** 어느 쪽으로 쓰는 단어인지 아는 것이
이 시험의 핵심 능력이라, `テレビ`를 `てれび`로 쓰면 오답입니다.
다만 "가나 종류가 다릅니다"라고 따로 짚어 주고, 그 실수만 모아 볼 수 있게 합니다.

## 입력 방식

아이패드 일본어 키보드의 `手書き` 모드로 **애플펜슬로 직접 씁니다.**
인식은 iOS가 하므로 앱이 만들 것은 없고, 손글씨 입력을 방해하지 않는 것이 앱의 일입니다.

펜이 없을 때를 위해 로마자 자동변환(`tabemono` → `たべもの`)과 화면 가나 자판을
보조로 둡니다. 가타카나 전환은 자동으로 하지 않습니다 — 그걸 고르는 것이 곧 답의 일부니까요.

## 다음에 필요한 것

1. 학습지·교재 사진 또는 PDF
2. 시험범위 (몇 과 ~ 몇 과, 또는 몇 쪽 ~ 몇 쪽)
3. 시험 날짜

구조와 배포 방식은 [`Jiri`](https://github.com/pwh831/Jiri)(지역이해 암기 퀴즈)와 같습니다 —
빌드 도구 없는 단일 HTML + 데이터 파일 + localStorage.
