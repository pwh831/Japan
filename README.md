# 일본어 단어 시험

일본어 시험범위 단어를 반복해서 외우고 직접 시험 보는 프로그램.

**현재 상태: 설계 단계.** 학습지·교재를 아직 받지 못해 단어 데이터가 비어 있습니다.

- 요구사항 정의서: [`docs/PRD.md`](docs/PRD.md)

## 문제 유형

| 유형 | 형태 | 예 |
|---|---|---|
| 일본어 → 뜻 | 뜻 5지선다 | `食べ物` → "음식" |
| 뜻 → 일본어 | 직접 타이핑 | "음식" → `たべもの` / `食べ物` |
| 예문 빈칸 | 문장 속 빈칸 채우기 | `好きな____は何ですか。` |

가운데 유형이 핵심입니다. 일본어 키보드 없이도 로마자로 치면 가나로 바뀝니다
(`tabemono` → `たべもの`).

## 다음에 필요한 것

1. 학습지·교재 사진 또는 PDF
2. 시험범위 (몇 과 ~ 몇 과, 또는 몇 쪽 ~ 몇 쪽)
3. 시험 날짜

구조와 배포 방식은 [`Jiri`](https://github.com/pwh831/Jiri)(지역이해 암기 퀴즈)와 같습니다 —
빌드 도구 없는 단일 HTML + 데이터 파일 + localStorage.
