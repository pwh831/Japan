# 일본어 단어 시험

일본어 시험범위 단어를 반복해서 외우고 직접 시험 보는 프로그램.

**앱: https://claude.ai/artifact/WnUDfbE5hL63tMvSxpHasb**

> 시험범위는 선생님이 주신 **「2026 일본어 회화 (2학기 1회고사 단어)」** 4쪽입니다.
> 원본은 `docs/2026-일본어회화-2학기1회고사-단어장.pdf`,
> **한국어 발음을 깔아 둔 사본**은 `docs/2026-일본어회화-2학기1회고사-단어장-발음.pdf`.
> 이어서 채웁니다. 앱 코드는 건드릴 것이 없습니다.

## 세 가지 시험

| # | 시험 | 무엇을 묻나 | 범위 | 현황 |
|---|---|---|---|---|
| 1 | **단어** | 낱말의 뜻과 표기 | 135항목 | ✅ 완성 |
| 2 | **표현** | 문장을 언제·어떻게 쓰나 | 16항목 | ✅ 완성 |
| 3 | **활용** | 동사 `ます`·`ましょう`·`たい`·`て` · `い`형용사 | 동사 35 · 형용사 6 | ✅ 완성 |

**셋은 외우는 방식이 다릅니다.** 단어는 항목을 외우면 끝이지만, 표현은 헷갈리는 짝과
가르는 것이 핵심이고, 활용은 규칙이라 하나를 알면 안 배운 동사도 맞힙니다.
한 통계에 섞으면 "80%"가 무엇을 아는 것인지 알 수 없게 되므로 진도를 따로 셉니다.

### 시험 1 · 단어

| 유형 | 형태 | 예 |
|---|---|---|
| 뜻 고르기 | 일본어 → 뜻 5지선다 | `みる` → "보다" |
| **직접 쓰기** | 뜻 → 일본어 타이핑 | "보다" → `みる` |
| 예문 빈칸 | 문장 속 빈칸 | `アニメを ____ よていだよ。` |

가운데가 핵심이고 출제 비중도 가장 높습니다. 숙달 판정도 이 유형만 셉니다 —
뜻만 아는 단어를 숙달로 넘기지 않기 위해서입니다.

### 시험 3 · 활용

| 유형 | 형태 | 예 |
|---|---|---|
| **활용형 쓰기** | 기본형 → 활용형 | `いく` + `て`형 → `いって` |
| 그룹 고르기 | 1류·2류·3류 (동사만) | `かえる` → 1류 (예외) |
| 기본형 되찾기 | 활용형 → 기본형 | `きます` → `くる` |

동사는 `ます`·`ましょう`·`たい`·**`て`**, `い`형용사는 부정 `~くない`·연결 `~くて`·과거 `~かった`.

**활용형은 데이터에 적지 않습니다.** 그룹 한 글자면 규칙으로 만들어집니다.
`て`형만 어간이 아니라 어미에서 갈립니다(음편) — `う·つ·る→って`, `ぬ·む·ぶ→んで`,
`く→いて`, `ぐ→いで`, `す→して`.

`はしる`·`しる`·`きる` 는 **기본으로 빠져 있습니다.** 단어장 4쪽 <자주 나오는 예외 1류
동사> 상자에만 있고 본문 어휘에는 없어 수업에서 안 다뤘을 수 있기 때문입니다
(`かえる`·`はいる` 는 1·2쪽 본문에도 `＊…(예외1류)` 로 나옵니다). 홈의 **참고 항목**
을 `넣기` 로 바꾸면 돌아옵니다.

**예외는 세 종류이고 전부 데이터로 적습니다.** 규칙만 믿으면 틀린 답을 정답으로 채점합니다.

| 종류 | 항목 | 규칙만 믿으면 |
|---|---|---|
| `る`로 끝나는 1류 | `かえる`·`はいる`·`はしる`·`しる`·`きる` | `かえます` |
| 음편 예외 | `いく → いって` | `いいて` |
| 형용사 불규칙 | `いい → よくない` | `いくない` |

숙달은 **항목별과 규칙별을 함께** 셉니다. 같은 (그룹 × 형)을 서로 다른 것으로 5번
연속 맞히면 규칙이 잡힌 것으로 보고, 그 뒤로는 평범한 것 대신 예외만 남깁니다.

### 시험 2 · 표현

| 유형 | 형태 | 예 |
|---|---|---|
| **대비 고르기** | 헷갈리는 짝 가르기 | `____ いく?` → `どこか` / `どこが` |
| 뜻 고르기 | 문장 → 뜻 | `あぶない!` → "위험해!" |
| 상황 → 표현 | 언제 쓰나 | "위험을 알릴 때" → `あぶない!` |
| 핵심어 쓰기 | 빈칸에 직접 | `____の しゅうまつ、なに する?` → `こんど` |

**대비 고르기가 이 시험의 이유입니다.** 교재가 105·107쪽 정리하기에서 `どこか`와
`どこが`를 나란히 놓고 비교시키는데, 붙여 놓고 비교시키는 건 내겠다는 뜻에 가깝습니다.

대비 문제에는 **한국어 뜻을 안 보여 줍니다.** "어딘가 갈까?"를 같이 띄우면 답이 새니까요.
그리고 **양쪽을 각각 3회씩** 맞혀야 숙달입니다 — 한쪽만 맞히면 가른 게 아닙니다.

문장 전체 타이핑은 안 합니다. 핵심어만 씁니다.

## 채점 규칙

**답은 가나로 씁니다.** 단어장이 한자+후리가나로 적으므로 한자는 **읽기용**입니다.
한자로 써도 정답으로 칩니다.

**히라가나와 가타카나는 구분합니다.** `テレビ` 를 `てれび` 로 쓰면 오답입니다.
다만 "가나 종류가 다릅니다" 라고 따로 짚어 주고, 그 실수만 모아 볼 수 있습니다.

**오타는 봐주지 않습니다.** 촉음 `っ`, 장음 `ー`, 탁점 한 글자가 다른 단어이기 때문입니다.

**한국어 발음은 정답을 본 뒤에만 나옵니다.** `しんかんせん` 밑에 작게 `싱칸센`.
문제 쪽에는 안 붙입니다 — 붙이면 가나를 읽는 연습이 사라집니다.
`か`=카·`が`=가로 적고 장음도 줄이지 않습니다(`コーヒー → 코오히이`). 모라 하나에
글자 하나여야 발음에서 가나를 되짚을 수 있기 때문입니다.

**닮은 글자는 되묻습니다.** `コ`/`ユ`, `シ`/`ツ`, `ソ`/`ン` 처럼 손글씨 인식이 자주
뒤바꾸는 짝만큼 다르면, 바로 오답 처리하지 않고 이렇게 쓴 게 맞는지 물어봅니다.
내가 틀린 건지 기계가 못 읽은 건지는 쓴 사람만 알기 때문입니다.

## 입력 방식

세 가지 중에 고릅니다.

- **직접** — 아이패드 일본어 키보드의 `手書き` 모드나 스크리블로 펜으로 씁니다
- **あ** — 로마자를 히라가나로 (`tabemono` → `たべもの`)
- **ア** — 로마자를 가타카나로 (`terebi` → `テレビ`)

가타카나 전환은 자동으로 하지 않습니다. 어느 가나로 쓰는 단어인지 고르는 것이
곧 답의 일부이기 때문입니다.

## 구성

```
index.html            앱 전체 (UI + 퀴즈 엔진 + 로마자 변환기)

data/phrases.js       시험 2 · 표현 16항목
data/verbs.js         시험 3 · 동사 35 + い형용사 6 (group 한 글자씩)
build.py              데이터를 인라인해 단일 HTML 생성
일본어-단어시험.html    배포용 단일 파일 (build.py 산출물)
tools/test-engine.js  채점기·변환기·활용 규칙·표현 계약·발음·범위 테스트 271항목
tools/smoke.js        실제 브라우저 종단 시험 (Playwright)
tools/kana-probe.html 손글씨 입력 점검기 (M2)
tools/annotate-pdf.py  시험범위 PDF 에 한국어 발음 깔기
docs/PRD.md           요구사항 정의서
docs/2026-일본어회화-…-단어장.pdf       시험범위 원본
docs/2026-일본어회화-…-단어장-발음.pdf  ↑ 에 한국어 발음을 깐 사본
```

## 고친 뒤

```bash
npm run build     # → 일본어-단어시험.html
npm test          # 271항목
npm run smoke     # 실제 브라우저로 앱을 열어 세션을 끝까지 풀어 본다
npm run pdf       # → docs/…-단어장-발음.pdf
```

`npm run pdf` 는 발음 규칙을 다시 적지 않고 **앱의 `pron` 함수를 그대로 떼어 씁니다.**
두 벌로 적으면 어긋나는 날이 오고, 어긋난 쪽이 어느 쪽인지 알 수 없게 됩니다.

`npm test` 는 **교재가 인쇄한 형과 엔진 출력을 대조합니다** — 102·103쪽 `ことば` 의
`まもります`·`あらいましょう`·`でましょう` 가 규칙에서 그대로 나오는지 봅니다.
엔진이 그럴듯한 형을 지어내면 여기서 걸립니다.

## 단어 추가

`data/words.js` 의 `WORDS` 배열에 객체를 하나 넣으면 됩니다.

```js
{ id:"w305", unit:"003", pos:"명사", word:"コーヒー", kana:"コーヒー",
  meaning:["커피"],
  examples:[{ ja:"毎朝コーヒーを飲みます。", ko:"매일 아침 커피를 마십니다.", form:"コーヒー" }] }
```

`kana` 가 정답 기준이므로 학습지 표기를 **글자 하나까지 그대로** 옮깁니다.
장음 `ー`, 촉음 `っ`, 탁점, 히라가나/가타카나 구분이 전부 채점에 쓰입니다.

구조와 배포 방식은 [`Jiri`](https://github.com/pwh831/Jiri)(지역이해 암기 퀴즈)와 같습니다.
