# 학습 원리 — 최소 시간으로 100점

받은 자료 세 권(「완벽한 기출분석 백서」 1~3권, 2026-10-19)을 인지과학 연구와 대조해
**근거가 있는 것만** 일본어 내신 공부 규칙과 앱 설계로 옮긴 문서다.
앱이나 공부법을 바꿀 때 이 문서를 기준으로 삼는다.

> 자료는 AI(Gemini)로 만든 정리본이라 진짜 연구와 지어낸 숫자·기전이 섞여 있다.
> 그래서 주장마다 근거 수준을 매겼다. **효과 없는 방법에 쓰는 시간이 곧 낭비**이므로
> 판정이 '약함·틀림'인 것은 규칙에 넣지 않았다.

## 2. 자료에 빠진 핵심

자료에서 제일 중요한 두 가지가 빠져 있다. 100점이 목표라면 이것이 뼈대다.

### 2.1 간격 반복 — 언제 다시 보는가 ◎

같은 시간을 써도 **몰아서 보지 않고 간격을 벌려** 보면 훨씬 오래 남는다
(Cepeda 외 2006 메타분석). 시험까지 남은 기간의 대략 10~20% 간격이 최적이다(Cepeda 외 2008).
자료의 '회독'은 무엇을 볼지만 말하고 **언제 볼지**를 말하지 않는다.

배운 날 기준: **당일 → 1일 → 3일 → 7일 → 14일 → 시험 주**.

### 2.2 졸업 기준 — 한 번 맞힘은 아는 것이 아니다 ◎

연속 재학습(Rawson & Dunlosky 2011): **한 세션 안에서 맞힐 때까지 → 다른 날 다시.**
서로 다른 날 3번 맞히면 오래 남고, 그 뒤로는 더 해도 남는 게 적다.

**졸업 = 서로 다른 날 3번, 직접 써서 맞힘.** 마지막은 첫 번째로부터 7일 이상 뒤.

### 2.3 100점은 '실수 0'이다

평균 90점과 100점의 차이는 모르는 것보다 **아는데 틀리는 것**(촉음 하나, 가나 종류)이다.
그래서 졸업한 항목도 시험 주에 한 번 더 확인하고, 실수 유형별로 따로 모아 본다(§2.5).

### 2.4 시험과 같은 형식으로 연습 ◎

전이 적합 처리(Morris 외 1977): 시험에서 하는 것과 같은 일을 연습해야 한다.
선생님 시험은 **손으로 가나를 쓰는 서답형 + 한두 글자 바꾼 철자 객관식 + 본문 서술형**이다.
그래서 연습도 펜으로 쓰기, 철자 고르기, 본문 문장 쓰기 순서로 비중을 둔다.

### 2.5 일본어 오답 분류

| 기호 | 원인 | 예 |
|---|---|---|
| 가 | 가나 종류 | `ロボット` → `ろぼっと` |
| 촉 | 촉음·장음·요음 | `ニュース` → `ニュス`, `ばしょ` → `ばしよ` |
| 탁 | 탁점·반탁점 | `がめん` → `かめん` |
| 활 | 활용·음편 | `聞く` → `聞きて` (○ `聞いて`) |
| 조 | 조사 | `ロボットが いる` → `ロボットは いる` (85쪽 필기) |
| 철 | 위 셋이 아닌 글자 하나 | `きく` → `きこ` |
| 뜻 | 뜻을 모름 | |

**가·촉·탁·철 = 아는데 틀린 것** → 시험 주에 이것만 모아 다시 쓴다.
**활·조·뜻 = 모르는 것** → 간격 반복으로 돌린다.

## 3. 일본어 내신 운영 규칙

한 쪽을 배운 날부터 시험까지. 목표 시간은 하루 10~15분.

| 언제 | 할 일 | 시간 |
|---|---|---|
| **수업 당일** | ① 본문을 보며 음성 따라 **소리 내어** 1회 ② 덮고 핵심 3가지 중얼거리기 ③ ことば 뜻 보고 **손으로 가나 쓰기**, 애매한 것 표시 | 10분 |
| 1·3·7·14일 뒤 | 앱이 내주는 **그날 복습분만** 푼다. 새로 보지 않는다 | 5~10분 |
| 주 1회 | 본문 백지 쓰기 — 선생님이 서답형 표시한 문장(85쪽 ⑧) 우선. 틀린 글자는 빨간색 | 10분 |
| 시험 D-7 | 변형문제를 시험 형식·시간으로. 오답은 §2.5 로 분류 | 30분 |
| 시험 D-3~D-1 | 가·촉·탁 실수 모음 + 졸업 안 된 항목만. 새 자료 금지 | 15분 |
| 시험 전날 밤 | 8시간 이상 잔다 | |

**하지 않는 것**: 교과서 다시 읽기만 하기 · 형광펜 칠하기 · 한 번 맞힌 단어 빼기 ·
가사 있는 노래 · 폰을 곁에 두기 · 시험 전날 밤샘.

## 4. 앱에 반영할 것

지금 앱은 인출(직접 쓰기)·오답 우선 출제·엄격한 가나 채점까지 되어 있다.
빠진 것은 **언제**와 **얼마나 확실히**다.
